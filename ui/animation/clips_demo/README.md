# Demo Clip Pack

Put your curated/best JSON clips in this folder.

- Folder: `ui/animation/clips_demo`
- Demo Mode ON: app will use this folder when it contains at least one `.json` clip.
- Demo Mode OFF: app uses `ui/animation/clips`.

Tip: keep clip file names the same as the original clips (for example `hello_2.json`) so existing token mapping works.
